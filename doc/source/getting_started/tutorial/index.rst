.. _tutorial:

Tutorial
########

This tutorial demonstrates how to use SAF and Plotly Dash to build a solution.
It is designed to provide newcomers with a step-by-step guide through the phases of solution development. Starting from a blank page, it shows you how to build a solution that solves a simple beam bending problem.

.. tip::
    You can find the code and the end result for this tutorial in the `simple-beam-bending <https://github.com/ansys/simple-beam-bending>`_
    repository on the Ansys public GitHub. You may refer to it at any time to check your progress.

    .. only:: internal

      This tutorial is based on a repository which lies in the Ansys GitHub organization. You need to be a member of this organization and to join the `Ansys Developers Team <https://github.com/orgs/ansys/teams/developers>`_.
