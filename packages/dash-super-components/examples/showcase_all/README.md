# Usage

This is a minimal SAF-based solution for showcasing and testing Super Components for Dash. Note that some components are only present in the UI, but not connected to any backend logic. To execute this example as explained below, you need to have `saf-cli` installed on your current system Python interpreter. For instructions to install `saf-cli`, refer to [the saf-cli "Getting Started" guide](https://saf-cli.docs.solutions.ansys.com/version/dev/getting_started.html).

Before running the commands below, ensure that no virtual Python environment is active and that your terminal is in the directory containing this README file.

1. Install the solution:

```bash
saf install .
```

2. Start the solution:

```bash
saf run .
```
