API reference
#############

This section contains the API reference for the
``ansys-solutions-dash-super-components`` library. The reference is organized
into two sections:

- :ref:`ref_api_components`—all public components in the
  ``ansys.solutions.dash_super_components`` package.
- :ref:`ref_api_utilities`—selected utility classes and functions from the
  ``ansys.solutions.dash_super_components.utils`` module which are commonly used in Dash apps
  that utilize the library.

For usage examples, screenshots, and configuration guides, see the
:external+saf:ref:`Dash Super Components user guide
<user_guide_frontend_dash_super_components_index>` in the SAF documentation.
