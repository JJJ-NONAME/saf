Utilities
#########

This section provides the API reference for selected utility functions
and classes that are commonly used in Dash apps that use the library.
The utilities are organized into three modules:

- :ref:`ref_api_utilities_svg_icons`—
  ``ansys.solutions.dash_super_components.utils.svg_icons``
- :ref:`ref_api_utilities_assets_server`—
  ``ansys.solutions.dash_super_components.utils.assets_server``
- :ref:`ref_api_utilities_config`—
  ``ansys.solutions.dash_super_components.utils.config``
