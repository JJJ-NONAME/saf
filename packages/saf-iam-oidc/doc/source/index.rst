IAM OIDC API reference
######################

The ``ansys-iam-oidc`` package provides OAuth2 and OpenID Connect (OIDC) capabilities,
including synchronous and asynchronous OIDC clients, FastAPI dependencies for token
validation, and token-handling utilities.
